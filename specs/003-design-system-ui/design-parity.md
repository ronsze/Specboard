# 시안 대조 점검표 (SC-011)

기준: `docs/Specboard-selection.pdf` (10쪽). 구현이 끝나면 화면마다 아래 요소를 직접 확인하고 체크한다. 범위 밖으로 명시한 요소는 만들지 않으므로 점검 대상이 아니다.

## 1쪽 Spec 화면
- [ ] 상단 내비: 로고, 보드·프로젝트·feature 이동, 승인 대기 배지, 멤버 관리, 사용자 이름, 내 역할 배지, 로그아웃
- [ ] feature 제목, 탭(Spec / 입력 N / 버전 이력)
- [ ] 버전 카드: 최신 배지, 버전 번호, 생성 시각, AI 갱신, "이력·비교" 링크, "이 버전 확정" 버튼(관리자만)
- [ ] 반영 대기 입력 안내 배너와 "입력 보기" 링크
- [ ] 항목 헤더: 결정·요구사항 개수, 범례(AI 정리, 출처, 미결)
- [ ] 항목 카드: 종류 배지, 번호(D-1/R-1), 문구, "AI 정리 · vN부터/변경/추가", "출처 N" 칩
- [ ] 출처 패널(펼침): `[n] IN-번호`, 종류, 제출자, 시각, 승인, 강조된 발췌, "원문 전체 보기"
- [ ] 미결 질문 레일: 열림·해소 개수, 안내문, 질문 카드(Q-n, 열림/해소, 출처 칩), "해소됨" 구분선, 답이 된 입력 칩, "질문에 답하는 입력 제출"
- [ ] 최근 버전 카드(3개)와 "전체 이력과 비교"

## 2쪽 버전 이력과 비교
- [ ] 버전 목록: 체크박스, A/B 표시, 현재 배지, 생성 방식, 시각, 근거 입력, 되돌림 버전의 "버전 N으로 되돌림 · 실행 이름", "이 버전으로 되돌리기"(관리자만), "이전 버전 N개 더 보기"
- [ ] 비교 헤더: "vA → vB 비교", 추가·삭제·변경·동일 개수, "변경 없는 항목도 보기"
- [ ] 비교 행: 추가(+), 삭제(−), 변경(~), 종류 배지, 번호, 문구, 출처/새 출처, 이전/이후 단어 강조, 질문 변경(열림→해소)
- [ ] 확정 상태 안내(되돌릴 수 없음, 확정 해제 링크)

## 3~4쪽 토큰과 컴포넌트
- [ ] 색 토큰 라이트·다크, 타이포 스케일, 간격, 모서리
- [ ] 배지 전 종류(입력 상태, spec 반영, spec 상태, 항목 종류, 입력 종류, 역할, 버전 방식)
- [ ] 버튼 종류(주 버튼, 보조, 위험, 텍스트, 포커스), "권한 없는 동작은 비활성이 아니라 그리지 않음"
- [ ] SpecItem + SourcePanel, InputCard, DiffRow, ConfirmModal(영향 목록, 취소 기본 포커스, Esc), RejectForm, LockControl

## 5쪽 입력 목록
- [ ] 제출 폼: 종류 세그먼트, 본문, 글자 수 0/50,000, "제출 후 흐름" 안내, 제출 버튼
- [ ] 필터 칩(전체, 내 대기 N, 반영 대기 N, 반려 N)
- [ ] 입력 카드: 종류, 상태, IN-번호, 제출자·시각, 본문, 승인자·시각, 반영 표시, "나와 관리자에게만 보임", 반려 사유 박스, "spec에 쓰이지 않음", 자동 승인 표시와 "관리자 제출", 펼치기와 글자 수, "이전 입력 N개 더 보기"

## 6쪽 승인 대기
- [ ] 보드 단위 제목과 개수, 안내문, 입력 카드(feature 링크), 반려…/승인 버튼, 반려 사유 폼(필수, 제출자에게 보임, 취소·반려 확정)
- 제외: "예정" 충돌 경고, "미결 질문 Q-n의 답이 될 수 있는 입력" 힌트

## 7쪽 멤버 관리
- [ ] 멤버 추가(이메일, 역할, 추가), 표(이름, 이메일, 역할, 추가일), "(나)" 표시, 마지막 관리자 강등 오류 행, 하단 역할 설명

## 8쪽 홈
- [ ] "내 보드", 보드 카드(이름, 내 역할 배지, 승인 대기 링크), 프로젝트 구분 행, feature 행(이름, 상태 배지, 버전·날짜, 반영 대기 입력 수 또는 "승인된 입력 없음", 갱신 중 "v2 → v3")

## 9쪽 로그인
- [ ] 로고, 한 줄 소개, 오류 안내(폼 위), 이메일·비밀번호, 로그인 버튼, "계정은 보드 관리자가 추가합니다"

## 10쪽 빈 상태·오류 상태
- [ ] 입력 없음, 승인된 입력 없음, 갱신 중(진행 막대와 "입력 N개를 읽고 있습니다"), 갱신 실패(관리자: 다시 시도 / 멤버·열람자: 안내만), 확정 상태 되돌리기 시도, 403, 404, 질문만 있고 항목 없음
